# Participant Baseline

## Participant-facing purpose

The workspace exists for participants, not administrators.

Participants should eventually use the workspace to begin self-qualification and claim workflows.

## Current-residence baseline

For Civic Infrastructure use, the CURRENT_RESIDENCE affordance is gained through SASE.

Other affordances and affected-status elements are not automatically granted. They must be claimed by the participant through later workflows.

## Design implication

The first workspace page should not attempt to implement those claim workflows.

It should only establish the participant-facing page path and the place where future JSON definitions will load.

## General runtime implication

For non-Civic uses, the same workspace concept can host other JSON-defined tools without requiring any Civic Infrastructure concepts.
